# Agrinho-2025
*Meu projeto tem o objetivo de incentivar as pessoas a plantar árvores, e a única coisar que tem que fazer é clicar com o mouse no lugar desejado, e plantará uma muda de árvore que crescerá em pouco tempo.
*Eu usei o chat gpt, pedi para ele criar a terra, depois o cenário, e por fiz as mudas.
*Pedi para ele criar também os códigos que fazem as plantas crescerem, resumindo eu usei IA para ir criando as partes do projeto.
