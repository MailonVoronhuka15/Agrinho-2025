# Agrinho-2025
*Este projeto tem o objetivo de incentivar as pessoas a plantarem árvores, e o que precisa fazer para interagir com o projeto é clicar com o mouse no lugar desejado, e plantará uma muda de árvore instantaneamente que crescerá em pouco tempo.
*Foi utilizado o chat gpt, pedi para ele criar a terra dizendo "crie um chao com terra escura", mandei criar o codigo para as mudas "faça nascer mudas de plantas onde eu clicar com o mouse",
pedi para fazer as mudas crescerem lentamente com o prompt "faça as mudas evoluirem", e por fim mandei um estágio onde a muda fica adulta, que pedi o seguinte, "faça com que as mudas mudem de estágio apos alguns segundos, virando uma muda adulta".
*Pedi para ele criar também os códigos que fazem as plantas crescerem, resumindo eu usei IA para ir criando as partes do projeto.
*Cada parte do código está organizado, descrito com // o que cada código executa, "os emojis usados", "como criei o sol, a terra e o céu", "desenhar as plantas ou árvores com os emojis", "escolhe o emoji baseado no estágio da planta",
"aumentar o tamanho da árvore com o tempo", "atualização do crescimento das plantas", "controlador da velocidade de crescimento", e por fim quando clicar na terra com o mouse gera uma planta no lugar do clique.
*Foi usado emojis para criar as núvens e as mudas, já o sol utilizei um círculo e colori manualmente com códigos "fill" para colorir e "ellipse" para criar o formato de círculo.🌱🌳☁️
*Foram usados estes emojis no projeto:"🌱" para a muda, "🌳" para a árvore adulta e "☁️" para núvens.
